# Mateo Bernardi

**Computer Engineering · Systems · Architecture**

I'm currently pursuing a degree in Computer Engineering at the National University of Córdoba (UNC), Argentina, interested in understanding how computing systems work beneath the abstractions — from processor architecture and operating systems to networking and distributed systems.

I enjoy building things, investigating technical problems, and validating ideas through practical experiments.

### Areas of interest

- **Computer Architecture** — RISC-V, processor design, FPGA and hardware verification.
- **Systems Engineering** — Linux, operating systems, networking and distributed systems.
- **Low-Level Software** — C, C++, Python and systems programming.
- **Infrastructure** — OpenWrt, Wi-Fi, network protocols and observability.

### Selected projects
